Notes: This page must be served from http://127.0.0.1:8000 (same origin) for the popup polling to read the redirect location. Place it in your Laravel `public/` folder or serve via `php artisan serve --host=127.0.0.1 --port=8000`.

How this works (comments)

  1. OAuth URL generation: The JS builds the authorization URL with response_type=code, your client id, the redirect URI, and scopes (openid email profile).
  2. Authorization code flow: The page opens a popup to that URL. After the user signs in, Google redirects the popup to your `redirect_uri` with ?code=AUTH_CODE. Because this page runs at the same origin as the redirect URI, it can read the popup location and extract the code.
  3. How to use the code in Laravel: Copy the shown code and POST it to your server endpoint (example below). The server exchanges it for tokens at Google's token endpoint.
  4. How to exchange the code for id_token: Server calls POST https://oauth2.googleapis.com/token with code, client_id, client_secret, redirect_uri, grant_type=authorization_code. Google returns id_token (JWT) and access_token.

Postman example

{
  "url": "POST http://127.0.0.1:8000/api/auth/google/exchange",
  "headers": {
    "Content-Type": "application/json"
  },
  "body": {
    "code": "PASTE_AUTH_CODE_HERE",
    "redirect_uri": "http://127.0.0.1:8000/google-callback"
  }
}

Laravel callback route example

use Illuminate\Http\Request;

Route::get('/google-callback', function (Request $request) {
    // This route receives the authorization code from Google.
    // For testing we simply return JSON containing the code.
    return response()->json([
        'code' => $request->query('code'),
        'error' => $request->query('error')
    ]);
});
